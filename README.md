# Parallel computing course work

Інструкція по запуску:
Вимоги
CMake ≥ 3.16
C++17 compiler

Збірка (з кореня server)
cmake -S . -B build
cmake --build build -j


cmake -S . -B build
cmake --build build --config Release -j

Запуск
build\Release\server.exe --port 8080 --index-dir "text_files\aclImdb" --threads 8 --scheduler-sec 10

Параметри запуску:

Сервер
--ip <ip> 
IP-адреса, на якій сервер буде очікувати з'єднання.
За замовчуванням: 127.0.0.1.

--port <port> або -p <port>
Порт для прив'язки сервера.
За замовчуванням: 8080.


Потоки
--threads <n>
Кількість потоків у ThreadPool.
Значення: 0 означає автоматичне визначення.
За замовчуванням: 0.



Скедулер
--scheduler-ms <ms>
Інтервал роботи планувальника в мілісекундах.
За замовчуванням: 10000.

--scheduler-sec <sec>
Альтернативний спосіб задати інтервал у секундах.

--no-scheduler
Повністю вимикає періодичну індексацію.



Індекс
--index-dir <path>
Шлях до директорії, файли в якій будуть проіндексовані.
За замовчуванням: text_files/aclImdb.

--remove-missing <0|1>
Чи видаляти з індексу записи про файли, які зникли з диска під час сканування.
Значення: 1 (true), 0 (false). Також приймає true/false.
За замовчуванням: 1.

--clear-index <0|1>
Чи очищувати весь індекс перед початком першого сканування при запуску.
За замовчуванням: 1.



--help або -h

Виводить інструкцію з використання та завершує роботу програми.
